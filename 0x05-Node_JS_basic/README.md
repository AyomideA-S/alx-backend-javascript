# Node.js Basics

This directory contains projects and exercises focused on the basics of Node.js, a JavaScript runtime built on Chrome's V8 JavaScript engine. The goal is to provide a foundational understanding of Node.js and its core modules.

## Introduction

Node.js allows developers to use JavaScript to write server-side code, enabling the creation of scalable and high-performance applications. This module covers the basics of Node.js, including its architecture, core modules, and basic usage.

## Learning Objectives

- Understand the architecture of Node.js
- Learn how to set up a Node.js project
- Explore core Node.js modules such as `fs`, `http`, and `path`
- Implement basic server-side functionality using Node.js

## Getting Started

To get started with the exercises, clone the repository and navigate to the project directory:

```sh
git clone <repository-url>
cd alx-backend-javascript/0x05-Node_JS_basic
```

## Installation

Install Node.js and the necessary dependencies:

```sh
npm install
```

## Usage

Run the JavaScript files using Node.js:

```sh
node <filename>.js
```

For example, to run the `0-console.js` file:

```sh
node 0-console.js
```
